Patna High Court Ex-Cadre Assistant Selection Process 2026

Preliminary/Screening Test (only if the number of applicants is high) Written Test Computer Proficiency Test Interview The final merit list is prepared based on marks secured in the Written Test and Interview only. Preliminary Test marks are used solely for shortlisting. There is negative marking of 0.25 marks for each wrong answer in the Preliminary Test and Written Test. Shortlisting ratios: 10 times the number of vacancies for the Written Test (if a Preliminary Test is held), 6 times for the Computer Proficiency Test, and 3 times for the Interview, based on the model roster point and reservation policy.
