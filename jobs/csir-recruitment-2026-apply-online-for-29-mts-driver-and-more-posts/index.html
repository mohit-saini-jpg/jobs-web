How Will CSIR Select Candidates?

Security Officer: qualifying physical test, then written test (Paper-I objective, Paper-II subjective) Security Assistant/Watch & Ward Assistant: Stage-I skill/physical and personality assessment test, Stage-II competitive written examination Junior Hindi Translator: open written competitive examination (Paper-I objective, Paper-II descriptive) Driver: qualifying skill test, then written test Multi-Tasking Staff: competitive written test Security Officer Paper-I threshold is 30%; final merit list is based on Paper-II Junior Hindi Translator final merit list is based only on Paper-II marks Security Assistant final merit list needs minimum threshold marks not less than 35% Ties resolved by date of birth, earlier essential degree and alphabetical order; Driver and MTS first by lesser negative marks

CSIR Exam Pattern 2026

Junior Hindi Translator, Driver and MTS: three marks per correct answer and one negative mark per wrong answer Security Officer Paper-I and Security Assistant personality test: one mark per correct answer, no negative marking Objective papers are OMR-based or computer-based, set in English and Hindi Threshold marks for Driver and MTS to be decided by the Competent Authority, CSIR
